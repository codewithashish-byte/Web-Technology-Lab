WEB TECHNOLOGY MSPA 2 & 3 — SOLUTIONS

Contains three simple browser-ready projects:
1. Student Task Manager
2. Simple Shopping Cart
3. Movie Search Application

HOW TO RUN:
- Extract this ZIP.
- Open the required project's folder.
- Double-click index.html or open it with Live Server in VS Code.
- API features require an internet connection.
- If an API is unavailable, the task manager/cart show a helpful message or fallback products.

Each project includes:
- index.html (HTML + CSS + JavaScript in one file for easy lab demonstration)
- App.tsx (basic React + TypeScript version)
- README.txt (features and run instructions)

Git commands are in GIT_COMMANDS.txt. The PDF names three problems but does not clearly label which belongs specifically to MSPA 2 versus MSPA 3, so all three are included.
